# Bca-Final-Year-Projects

The project name is "Krushi Saarthi" and it is a centerlized platform for agriculture equipments purchasing and selling.

# KRUSHI SAARTHI – PROJECT INSTALLATION & RUNNING INSTRUCTIONS

## Important:

1. First, install Notepad++ and XAMPP Server on your computer.

2. After installing XAMPP Server, open the XAMPP installation folder.

3. Go to the htdocs folder.

4. Inside the htdocs folder, keep all the (.php) files of the project.

5. Inside the project folder, create an images folder.

6. Keep all the required images inside the images folder.

7. Also, create a db.php folder.

8. Inside the db.php folder, keep the db.php file.

9. Also, create an uploads folder.

10. Keep all the required uploaded files inside the uploads folder.

11. After arranging all the files and folders properly, save everything inside the htdocs folder.

---

# Project Folder Structure

The project should be arranged systematically like this:

htdocs

# Steps to Run Projects:

### Step 1:

Start the XAMPP Server.

### Step 2:

Start Apache and MySQL Database from the XAMPP Control Panel.

### Step 3:

Open your Chrome Browser.

### Step 4:

Type the following URL in the browser:

localhost/Krushi%20Saarthi/index.php

### Step 5:

Press Enter.

The Krushi Saarthi project will open in the browser.

---

# Database – SQL File

Note: I will upload the SQL file for you.

The SQL file name is:

"Krushi Saarthi.zip"

You can upload/import this SQL file through phpMyAdmin.

### To import the database:

1. Start XAMPP.

2. Start Apache and MySQL.

3. Open phpMyAdmin in your Chrome Browser.

4. Create/select the required database.

5. Import the Krushi Saarthi.zip SQL file.

6. After successfully importing the database, make sure the db.php file contains the correct database connection details.

7. Then open the project using:

localhost/Krushi%20Saarthi/index.php
